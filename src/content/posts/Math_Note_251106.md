### 一、可导性

​ 可导性的证明要用定义来证明，只有对于该点有定义的函数，其导函数在该点才可能有定义

​ 例如，对于函数

$$
f(x) =
\begin{cases}
x^2sin{\frac{1} {x} }, & x \neq 0 \\\
0, & x = 0
\end{cases}
$$

​ 由于其在$x=0$处无定义，故不可以求导来证明左右导数是否相等

### 二、经典反函数的求导

​ 我们通过反三角函数的求导来说明反函数的求导

​ 对于反函数$y=arcsinx$我们对其求导

$$
y^{`}=\frac{1} { {siny} ^ {`} }=\frac{1} {cosy}
$$

​ 又：

$$
cosy={\sqrt{1-sin^{2}y}={\sqrt{1-x^{2} } } }
$$

​ 则：

$$
(arcsin)^{\`}={\frac{1}{ {\sqrt{1-x^{2} } } } }
$$

##### 提问：为什么不可以写成$y^ { ’ }= {\frac { 1 } { x ^ {’ } } }$

##### 答：此处$y=arcsinx$,$x=siny$,两式互为反函数，这样的表述方式只是重述了定理${\frac{ {\mathrm{d}y} } { {\mathrm{d}x} } }={\frac{1} {\frac{ {\mathrm{d}x} } { {\mathrm{d}y} } } }$
