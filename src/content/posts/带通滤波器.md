#### 一、传递函数

##### 1.标准形式传递函数

$$
H(s)={\frac{Y(s)}{U(s)} }={\frac{({\frac{ { {\omega}_{0} } } {Q} } {\times}{s})} {({s^2} {+}{ {\frac{{\omega}_{0} } {Q} }s}{+}{ {\omega}_{0}^{2} }) } }
$$

##### 2.通用形式传递函数

$$
H(s)={\frac{Y(s)} {U(s)} }={\frac{({b_{1} } {s})} {(s^{2}+a_{1}s+a_{0}) } }
$$

##### 3.参数说明

· `s`:拉普拉斯变量

· `Y(s)`:输出信号的拉普拉斯变换

· `U(s)`:输入信号的拉普拉斯变换

· `ω₀`:滤波器中心频率，其中${ {\omega}=2{\pi}f}$

· `Q`:品质因数，决定滤波器带宽

​ 对应关系: $a_{1}={\frac{ {\omega}_{0} } {Q} }$,$a_{0}={\omega}_{0}^{2}$,${b_1}={\frac{ {\omega}_{0} }{Q} }$
